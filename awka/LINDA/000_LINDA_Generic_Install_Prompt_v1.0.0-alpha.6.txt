LINDA GENERIC HARDENED DOMAIN ACTIVATION DIRECTIVE v1.0.0-alpha.6

PURPOSE
Activate the three-file LINDA Generic Hardened Domain Runtime v1.0.0-alpha.6 on a successfully bootstrapped AWKA Kernel v1.0.0-alpha.4.

This directive is procedural only. It is not an uploaded component, behavioral authority, executable component, Domain Model, or organization-configuration file. The Manifest declares the release. The Model defines behavior. The Verification Suite tests conformance.

The release contains an embedded generic organization template. A separate organization-configuration file is not required for Domain activation. Authorized organization-specific overrides remain optional after activation and must remain non-evidentiary.
